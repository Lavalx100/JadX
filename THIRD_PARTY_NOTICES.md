The JadX IDE embeds Monaco Editor, the browser code editor from VS Code, and @monaco-editor/react. Their MIT license texts are included in licenses/monaco-editor-MIT.txt and licenses/monaco-react-MIT.txt. Monaco's bundled third-party notices are in licenses/monaco-editor-third-party.txt.

## Code OSS and code-server

The optional IDE workbench downloads the Apple silicon standalone release of coder/code-server v4.143.1 on first use. It contains Code OSS v1.143.1, distributed under the MIT License. The upstream code-server and Code OSS MIT license texts are in licenses/code-server-MIT.txt and licenses/code-oss-MIT.txt; Code OSS's third-party notices are in licenses/code-oss-third-party.txt.

The extension gallery is Open VSX. Code OSS forks cannot use Microsoft's Visual Studio Marketplace under its published terms. Extensions and terminal commands run with the logged-in macOS account's permissions.
